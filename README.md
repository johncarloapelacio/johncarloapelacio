## Featured project

### [Industrial Agent Evaluation Lab](https://github.com/johncarloapelacio/industrial-agent-evaluation-lab)

A maintenance agent investigates equipment problems through real REST services and PostgreSQL. The lab records every tool call, checks permissions and resulting database state, and makes failed runs easy to inspect and replay.
